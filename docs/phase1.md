When starting fleet by running 'fleet', A picker will show up.
This picker shows the saved projects and the option to create a new project.

New project asks for the projects root directory and the name of the project.
Fleet will open after this within the projects root directory.

Fleet dashboard will show up. On the left side, it will show a ai harness, 
now this will be claude. The right pane will show the agent dashboard.
Now we need an add repository command, button and keybind. 
We either create a new repository or we can add an existing one.
The repository will be bare repos where the worktrees are created. 
While creating or adding a repository, the user will be prompted to enter 
the default branch name, which will be used to create the worktrees.
